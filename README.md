# FERRONETWORK
Projecte Intermodular 26-27 

Context:
El projecte consisteix a simular una xarxa empresarial que connecti dues seus situades en diferents països, permetent als usuaris compartir informació i comunicar-se de manera segura.
Per aconseguir-ho, es crearà una intranet accessible únicament mitjançant VPN, amb una pàgina web funcional, un servidor de correu electrònic i una plataforma de comunicació similar a Slack (workspace).
També s'implementaran serveis com proxy, bases de dades i firewall, garantint el xifratge de les comunicacions i realitzant proves de hacking ètic per comprovar la seguretat de tota la infraestructura.


Abast: 
- Xarxa privada: connexió entre dues seus mitjançant servidors.
- VPN: accés remot segur amb ZeroTier o WireGuard.
- Intranet: pàgina web funcional accessible només mitjançant VPN.
- Servidor de correu: creació de diversos comptes per als usuaris.
- Comunicació tipus Slack: espai de treball per intercanviar missatges i fitxers.
- Base de dades: emmagatzematge de la informació dels usuaris.
- Proxy i firewall: control i protecció de les connexions.
- Seguretat: xifratge de les comunicacions i control d'accessos.
- Pentesting: realització de proves de hacking per detectar vulnerabilitats i comprovar la seguretat de la xarxa.
